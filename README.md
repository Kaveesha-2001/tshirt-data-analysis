# T-Shirt Stock Data Visualization Project 👕📊

This project was developed to practice and demonstrate fundamental **Data Visualization** techniques using **Python**. It involves generating a synthetic dataset of T-shirt inventory and analyzing it through visual representation.

## 🚀 Project Overview
The workflow of this Python notebook includes the following key stages:

1.  **Data Generation:** Using Python's `random` and `string` libraries to create a dataset of 1,000 entries, including T-shirt IDs, Sizes (S, M, L, XL, XXL), Colors, Prices, and Stock levels.
2.  **Data Management:** Storing and structuring the generated data into a `Pandas` DataFrame for easy manipulation.
3.  **Data Grouping:** Aggregating the total stock counts based on T-shirt sizes to identify inventory distribution.
4.  **Data Visualization:** Utilizing the `Matplotlib` library to create a Pie Chart that visually represents the stock share for each size.

## 🛠️ Tech Stack (Libraries Used)
The following Python libraries were used in this project:
*   **Pandas:** For data manipulation and structured analysis.
*   **Matplotlib:** For creating static, high-quality visualizations.
*   **Numpy:** For supporting mathematical operations.
*   **Random & String:** For generating realistic synthetic data.

## 📊 Key Findings
The generated visualization provides an immediate understanding of which T-shirt sizes are most prevalent in the current stock, helping in inventory decision-making.

*   Generating synthetic datasets for testing and prototyping.
*   Mastering basic **Pandas** operations like `groupby()` and DataFrame creation.
*   Customizing charts (labels, colors, and percentages) using **Matplotlib**.
